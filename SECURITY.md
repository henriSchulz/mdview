# Security

If you find a way to make the app do what it should not — a note that reaches beyond itself,
a shared link that shows more than its note, a way to another person's repository or sign-in —
please report it privately: on GitHub, *Security › Report a vulnerability* in this repository.
Please do not open a public issue for it.

What helps: the version (Settings › About), the system, and the smallest note or steps that
show it.
