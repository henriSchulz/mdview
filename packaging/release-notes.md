### Which file?

| Your computer | The file |
|---|---|
| Windows | `…-windows-x64-setup.exe` |
| Debian, Ubuntu, Mint | `…-linux-<arch>.deb` |
| Fedora, openSUSE | `…-linux-<arch>.rpm` |
| any other Linux | `…-linux-<arch>.AppImage` |

`x64` is for Intel and AMD processors, `arm64` for ARM. The Windows installer is not signed, so Windows warns before it runs it.
