# Markdown Notes for macOS

The native shell (Swift, WKWebView) for the app in this repository. Build with `./build.sh` (`--install` copies it
to `~/Applications`), start with `../bin/mdview-mac [file-or-folder]`. How it is put together and how it differs
from the Linux app: [`../docs/MACOS.md`](../docs/MACOS.md).
